1. Introduction & Overview

BuildTrack Inventory System is a web-based application designed for construction companies to manage:

  • Projects — Track construction projects with team members, timelines, and progress
  • Purchase Orders — Create, approve, and track material orders through their full lifecycle
  • Inventory & Materials — Manage SKUs (Stock Keeping Units), quotations, and deliveries
  • Equipment & Tools — Track company assets, borrowing, and returns
  • Delivery Tracking — Assign drivers, track shipments, and collect delivery evidence
  • Reports — Generate comprehensive reports with PDF/Excel export
  • Notifications — Real-time alerts for order updates, approvals, and more

7. Quotation Requests

Quotations define the material requirements for a project and serve as the baseline for tracking progress.

  1. Go to Quotation Request page or the project's Quotation section
  2. Select the project
  3. Click "Create Quotation"
  4. Add material rows (Material Name, Unit, Quantity)
  5. Click "Save"
How Quotations Affect Progress: Project progress is calculated by comparing quoted quantities vs. delivered order items. Without a quotation, no progress bar is shown.

16. Step-by-Step Tutorials

Tutorial 1: Complete Order Workflow (End to End)

Phase 1: Create the Quotation

  1. Go to Projects → Click on your project
  2. Click "View Quotation"
  3. Click "Create Quotation"
  4. Add materials: e.g., "Cement" - sack - 1000, "Steel Bars" - pcs - 500
  5. Click "Save"

Phase 2: Create and Submit an Order

  1. Go to Order & Tracking → Select your project
  2. Click "+ Create Order"
  3. Select the quotation, add items, fill supplier info
  4. Click "Create Order" then "Submit"

Phase 3: Approve the Order

  1. Log in as an Approver
  2. Find the pending order and review items
  3. Click "Approve" (or "Reject" with a reason)

Phase 4: Track Delivery

  1. Change status to "Ordered" then "In Transit"
  2. Assign a driver with plate number and materials
  3. Driver uploads evidence photos along the way
  4. Mark as "Delivered" when materials arrive

Phase 5: Receive and Close

  1. Receiver opens the delivered order
  2. Uploads receiver evidence (photos)
  3. Marks as "Fully Received"
  4. Project progress updates automatically!

Tutorial 2: Setting Up a New Project

  1. Go to Projects → Click "+ Create Project"
  2. Fill in: Name, Code, Location, Description, Dates
  3. Click "Create"
  4. Go to Team tab → Add team members
  5. Click "View Quotation" → Create quotation with all materials
  6. Go to Order & Tracking to start creating orders

Tutorial 3: Generating a Report

  1. Go to Reports page
  2. Select a project from the dropdown
  3. Click "Generate Report"
  4. Browse collapsible sections: Projects, Orders, Materials, Equipment, Team
  5. Click PDF, Excel, or Print to export

17. Tips & Best Practices

Always Create Quotations First

Creating a quotation before placing orders allows the system to track project progress automatically. Without a quotation, no progress bar appears.

Use Consistent SKU Names

Use the same SKU codes/names as in your quotation for accurate progress tracking.

Upload Delivery Evidence

Always upload photos when receiving deliveries. This creates a verifiable record.

Check the Dashboard Daily

The Dashboard shows pending orders, active projects, and low stock. Check it first thing each day.

Security Reminders

  • Never share your login credentials
  • Change your password if compromised
  • Log out when using shared computers
  • Auto-logout after 10 minutes of inactivity

18. Frequently Asked Questions (FAQ)

Q: I can't see the progress bar on my project. Why?

A: Create a quotation with material requirements first. The progress bar calculates based on delivered orders vs. quotation.

Q: My order shows 0% received even though materials were delivered. Why?

A: The order status must be "Delivered" or beyond for materials to count as received.

Q: I submitted an order but it disappeared. Where is it?

A: It moved to "For Approval" column on the workflow board. An approver needs to review it.

Q: Can I edit an order after it's been approved?

A: Only limited edits (supplier, notes). Item changes require rejecting and recreating.

Q: How do I change my company?

A: Only a Super Admin can reassign users to different companies.

Q: The system logged me out. What happened?

A: Auto-logout after 10 minutes of inactivity. Log back in to continue.

Q: Can I access BuildTrack from my phone?

A: Yes! BuildTrack is responsive and works on mobile devices.

Q: How is project progress calculated?

A: Progress = (Total Delivered Quantity / Total Quoted Quantity) × 100. Only orders with "Delivered" status or beyond are counted.

Q: Do I need to select a company when logging in as Super Admin?

A: No. Super Admins can log in without selecting a company and see all data system-wide.
